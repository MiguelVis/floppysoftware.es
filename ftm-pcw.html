Find that mine!

https://github.com/MiguelVis/RetroProjects

This is a clon of Minesweeper (yes, one more!).

The aim of the game is to find all the mines of the board, putting a flag over them and uncovering the other squares.

You can play with the mouse or the keyboard.

This game was developed using MESCC (Mike's Enhanced Small C Compiler - my version of Small C), and Samaruc libraries - my GUI (Graphical User Interface) for the Amstrad PCW.

Also, there is a version available for plain CP/M.
